# GradingCards

Expo-App (React Native + TypeScript) zum Suchen, Vergleichen und Kaufen von Pokémon-Karten.

- Daten: [Pokémon TCG API](https://docs.pokemontcg.io) (Preise: Cardmarket in EUR, TCGplayer in USD)
- Suche → zwei Karten antippen → „Vergleichen“; die günstigere Karte (Cardmarket) wird grün markiert
- „Zum Angebot“ öffnet den Shop-Link (Kaufabwicklung in der App folgt später)

```
npm install
npm start
```
